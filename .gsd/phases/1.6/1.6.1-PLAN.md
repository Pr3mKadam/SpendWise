# Plan 1.6.1: Setup Dexie.js Database & Data Migration

## Objective
Establish a robust local database using Dexie.js (IndexedDB) to replace `localStorage` limits, and implement a migration utility to transfer existing user data.

## Context
- .gsd/ROADMAP.md
- .gsd/phases/1.6/RESEARCH.md
- `src/store/index.ts`
- `src/types/index.ts`

## Success Criteria
- [ ] Dexie.js is installed and schema is defined.
- [ ] Application state persists across reloads via IndexedDB.
- [ ] Old localStorage data is successfully migrated to IndexedDB.
