# Plan 1.9.2: Manual Subscription Entry

## Objective
Add a manual entry modal to allow users to add subscriptions manually. The current system relies on auto-detecting recurring transactions, but users need a way to proactively add their subscriptions.

## Context
- `src/components/features/subscriptions/SubscriptionManager.tsx`
- `src/components/common/ui/Button.tsx`
- `src/store/useStore.ts`

## Tasks
