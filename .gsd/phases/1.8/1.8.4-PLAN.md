# Plan 1.8.4: Performance Audit + Bundle Optimization

## Objective
Reduce the production bundle size and improve perceived performance. Target: bring JS bundle under 900KB (currently ~1.4MB). Use Vite manual chunking, dynamic imports for heavy views, and audit for unused dependencies.

## Context
- `vite.config.ts`
- `package.json`
- `src/App.tsx`
- `src/components/views/` (all view files)

## Tasks

<task type="auto">
  <name>Add Vite manual chunks and lazy-load heavy views</name>
  <files>vite.config.ts, src/App.tsx</files>
  <action>
    In `vite.config.ts`, add `build.rollupOptions.output.manualChunks` to split vendor bundles:

    ```ts
    manualChunks: {
      'vendor-react': ['react', 'react-dom'],
      'vendor-motion': ['framer-motion'],
      'vendor-charts': ['recharts'],
      'vendor-lucide': ['lucide-react'],
      'vendor-ocr': ['tesseract.js'],
    }
    ```

    In `src/App.tsx`:
    - Convert static imports for heavy views to `React.lazy()`:
      - `AdvisorView` → `const AdvisorView = React.lazy(() => import('./components/views/AdvisorView'))`
      - `ReportsView` → `const ReportsView = React.lazy(() => import('./components/views/ReportsView'))`
      - `BankSyncView` (if exists) → same pattern
    - Wrap the view-rendering switch/router in `<React.Suspense fallback={<div className="p-8 text-center text-[var(--text-muted)]">Loading...</div>}>`

    Avoid:
    - Do NOT lazy-load `DashboardView` — it is the initial view and must be eagerly loaded
    - Do NOT change the navigation logic or sidebar — only the import strategy changes
  </action>
  <verify>
    Run `npm run build` and check `dist/assets/` — there should be multiple JS chunk files.
    The largest single chunk should be under 500KB (gzipped).
    `npx tsc --noEmit` must still pass.
  </verify>
  <done>
    Build succeeds. `dist/assets/` contains separate `vendor-charts`, `vendor-motion`, `vendor-ocr` chunks.
    AdvisorView and ReportsView are not in the initial bundle.
  </done>
</task>

<task type="auto">
  <name>Audit and prune unused dependencies</name>
  <files>package.json</files>
  <action>
    Run `npm ls --depth=0` to list direct dependencies.

    Check for and remove any packages that are no longer used after the offline migration:
    - `@google/genai` — should already be gone; confirm with `grep -r "@google/genai" src/`
    - Any Supabase or Convex packages — confirm with `grep -r "supabase\|convex" src/`
    - If found, remove them: `npm uninstall <package-name>`

    Also add to `vite.config.ts` under `optimizeDeps.exclude`: `['tesseract.js']` to prevent Vite from pre-bundling this large library (it handles its own worker loading).

    Avoid:
    - Do NOT remove `framer-motion`, `recharts`, `lucide-react`, `zustand`, `tesseract.js` — all are actively used
  </action>
  <verify>
    `grep -r "@google/genai" src/` returns no results.
    `npm run build` completes without warnings about missing modules.
    `npx tsc --noEmit` passes.
  </verify>
  <done>No cloud AI or removed-backend packages remain in node_modules or src imports. Build completes cleanly.</done>
</task>
