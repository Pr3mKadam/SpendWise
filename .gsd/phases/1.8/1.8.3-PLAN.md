## Tasks

<task type="auto">
  <name>Build TaxPredictor component</name>
  <files>src/components/features/analytics/TaxPredictor.tsx</files>
  <action>
    Create `TaxPredictor.tsx` — an offline Indian income tax estimator card:

    Logic (all local, no API):
    - Accept `annualIncome: number` as a prop (derive from `monthlyStats.totalIncome * 12`)
    - Apply FY2024-25 New Tax Regime slabs:
      - 0–3L: 0%
      - 3–7L: 5%
      - 7–10L: 10%
      - 10–12L: 15%
      - 12–15L: 20%
      - 15L+: 30%
    - Standard deduction: ₹75,000 (New Regime 2024)
    - Calculate: `taxableIncome = max(0, annualIncome - 75000)`, then apply slab rates
    - Output: `estimatedTax`, `effectiveRate` (%), `monthlyTaxProvision` (tax/12)

    UI layout:
    - Card header: `Calculator` icon + "Tax Liability Predictor" title + "(FY 2024-25 New Regime)" subtitle in muted text
    - 3 stat rows: Gross Annual, Taxable Income, Estimated Tax — each with value and label
    - A colored bar showing effective tax rate: green (<10%), amber (10-20%), red (>20%)
    - Footer: "Monthly provision needed: ₹X" in a teal highlight box
    - A small disclaimer: "Estimate only. Consult a CA for filing."

    Avoid:
    - Do NOT make any API calls — all calculations are pure JS math
    - Do NOT hardcode income — derive from the prop
  </action>
  <verify>`npx tsc --noEmit` passes. File exports `TaxPredictor` as named export.</verify>
  <done>TaxPredictor.tsx computes correct slab-based tax for sample income values (e.g. ₹8L → ~₹30,000 tax). No TS errors.</done>
</task>
