# Plan 1.8.1: Dashboard Hero Redesign

## Objective
Transform the DashboardView into a premium, visually stunning financial cockpit. Replace the plain grid of MetricCards with an immersive hero section featuring a large balance display, animated gradient background, real-time sparkline, and contextual greeting. This is the single biggest UX win and sets the tone for the whole app.

## Context
- `.gsd/SPEC.md`
- `.gsd/ARCHITECTURE.md`
- `src/components/views/DashboardView.tsx`
- `src/components/features/dashboard/MetricCards.tsx`
- `src/hooks/useFinanceState.ts`
- `src/index.css`

  <action>
    Create a new `DashboardHero.tsx` component that replaces the top MetricCards section.

    Design requirements:
    - Full-width card with a dark gradient background (e.g. `from-[#0f172a] via-[#1e2a45] to-[#0f2027]`) with a subtle animated mesh/noise texture overlay using CSS `@keyframes`
    - Large centered balance display: label "Total Balance" in small caps, then the animated count-up number in 56px+ Manrope Black
    - Below balance: a single horizontal row of 3 mini-stats (Income | Expenses | Net) with teal/green/red color coding
    - A thin 1px sparkline (using Recharts `<LineChart>` with no axes, just the line) showing the last 14 days of balance trend
    - Top-right corner: a contextual greeting chip: "Good Morning, Saver 👋" based on time of day
    - Bottom strip: a health score progress bar (0-100) with label "Financial Health" using `var(--teal)` fill
    - Use `motion.div` from framer-motion for entrance animation: `initial={{ opacity:0, y:20 }}` → `animate={{ opacity:1, y:0 }}`

    Avoid:
    - Do NOT use Tailwind gradient classes — use inline `style` or CSS variables for theme compatibility
    - Do NOT remove the `useCountUp` hook — reuse it for the balance number
